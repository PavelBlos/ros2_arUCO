# Карта и калибровка ArUco

Веб-интерфейс на порту 8080 хранит карту меток в
`/home/raspberry/arUco_termit/shared_config/tags_config.yaml`. Изменения
записываются атомарно, получают новую ревизию и применяются детектором только
после сверки epoch, revision и SHA-256.

## Первый запуск

1. Укажите диаметр колеса, обычный размер стороны метки и высоту потолка в
   разделе «Физические параметры».
2. Установите робота под первой видимой меткой.
3. После физической проверки положения камеры задайте её extrinsics со статусом
   `verified` через `/api/extrinsics`.

Для установленной на этом роботе камеры рабочая ориентация равна
`roll=0`, `pitch=-pi/2`, `yaw=0`: низ изображения направлен вперёд по
`base_link +X`, правая сторона изображения — вправо (`base_link -Y`).
4. Нажмите значок якоря у видимой метки. Она станет началом карты `(0, 0)`.

Подтвердить якорь нельзя по старым данным кадра или при непроверенной
калибровке камеры.

## Добавление меток

- Для измеренных координат заполните ID, сторону, X и Y и нажмите «Сохранить
  координаты». Такая запись сразу получает состояние `confirmed`.
- Для автоматического определения координат подведите робота джойстиком к новой
  красной метке, укажите ID и сторону, затем запустите мастер. Робот медленно
  совмещает свой центр с меткой, останавливается, ждёт затухания колебаний и
  усредняет не менее 30 кадров. Проверьте результат и нажмите «Подтвердить».

Знакомая подтверждённая метка обводится зелёным, неизвестная — красным.
Отключённые и неподтверждённые записи имеют отдельные диагностические цвета.

Мастер не начинает движение при конфликте управления, рассинхронизации карты,
потере ESP32 или одометрии. Потеря целевой метки либо heartbeat немедленно
вызывает остановку. Кнопка «Стоп» доступна во всех состояниях мастера.

## Точность нескольких меток

Для одного кадра каждая подтверждённая метка сначала даёт независимую гипотезу
позы. Две гипотезы проходят критерий Махаланобиса; конфликт разрешается по
одометрии только при однозначном результате. Для трёх и более меток выбирается
согласованное множество целыми метками, после чего все их углы совместно
уточняются `solvePnPRefineLM`. Метка с чрезмерной ошибкой репроекции исключается
целиком. При неоднозначном конфликте система сохраняет одометрическую позу и не
совершает скачок координат.
