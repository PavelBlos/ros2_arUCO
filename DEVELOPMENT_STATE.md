# Состояние разработки проекта (Context Handoff)

Этот файл создан для того, чтобы вы могли мгновенно передать текущий контекст разработки любому ИИ-ассистенту (включая меня) на новом компьютере. 

---

## 📋 Краткая сводка проекта
* **Цель**: Локализация мобильного робота в реальном времени с точностью ~1 см с помощью направленной вверх глобальной затворной CSI-камеры (IMX296) на Raspberry Pi 5 по потолочным ArUco-маркерам.
* **Стек**: ROS 2 Jazzy, Python 3, OpenCV, SciPy.
* **IP-адреса**: Raspberry Pi 5 (`192.168.31.215`), основной ПК (`192.168.31.142`).

---

## 🛠️ Что полностью реализовано и проверено

1. **Калибровка и детекция**:
   - Камера полностью сфокусирована и откалибрована (RMS ошибка `0.3209`). Параметры сохранены в `camera_info.yaml`.
   - Написан универсальный скрипт записи видео `video_record` с поддержкой одновременного стриминга в браузер (позволяет целиться в калибровочную доску).
   - Детектор маркеров ArUco стабильно работает на частоте 30 Гц.

2. **Фильтрация и локализация**:
   - Внедрена низкочастотная фильтрация: **EMA** для позиции (X, Y, Z) и сферическая линейная интерполяция **Slerp** для ориентации (кватернионы). Это полностью устранило sub-centimeter шум (jitter) координат.
   - Коэффициент сглаживания вынесен в динамический параметр `filter_alpha` (по умолчанию `0.15`).

3. **Сглаживание типов параметров ROS 2**:
   - Все ноды (`video_tag_detector`, `localization_node`, `camera_calibrator`) переведены на поддержку **динамических типов параметров** (`dynamic_typing=True`). Это исправило ошибку `InvalidParameterTypeException` при передаче численных аргументов из терминала (например, `video_path:=0` для запуска живой камеры).

4. **Real-Time Web UI (Веб-интерфейс)**:
   - В `localization_node.py` встроен легковесный многопоточный веб-сервер на стандартных библиотеках Python.
   - При запуске локализации на малине автоматически поднимается веб-интерфейс на порту **`8080`** (`http://192.168.31.215:8080/`).
   - Интерфейс представляет собой интерактивную 2D-карту на Canvas (с поддержкой Zoom и Drag/Pan), которая в реальном времени отображает сетку, потолочные маркеры (подсвечиваются зеленым при обнаружении), положение робота с вектором направления движения, а также сглаженную и сырую траектории движения.

5. **Сохранение графиков по Ctrl+C**:
   - Нода локализации перехватывает сигнал прерывания (`KeyboardInterrupt`). При ручной остановке процесса локализации по **Ctrl+C** она автоматически рассчитывает финальную длину пути и сохраняет сравнительный график траектории `trajectory_plot.png`.
