# Состояние разработки проекта (Context Handoff)

Этот файл создан для того, чтобы вы могли мгновенно передать текущий контекст разработки любому ИИ-ассистенту (включая меня) на новом компьютере. 

---

## 📋 Краткая сводка проекта
* **Цель**: Локализация мобильного робота в реальном времени с точностью ~1 см с помощью направленной вверх глобальной затворной CSI-камеры (IMX296) на Raspberry Pi 5 по потолочным ArUco-маркерам и слияния с одометрией шаговых двигателей.
* **Стек**: ROS 2 Jazzy, Python 3, OpenCV, SciPy.
* **IP-адреса**: Raspberry Pi 5 (`192.168.31.213`), основной ПК (`192.168.31.142`).

---

## 🛠️ Что полностью реализовано и проверено

1. **Калибровка и детекция**:
   - Камера полностью сфокусирована и откалибрована (RMS ошибка `0.3209`). Параметры сохранены в `camera_info.yaml`.
   - Написан универсальный скрипт записи видео `video_record` с поддержкой одновременного стриминга в браузер.
   - Детектор маркеров ArUco стабильно работает на частоте 30 Гц.

2. **Слияние датчиков (Sensor Fusion)**:
   - Внедрена низкочастотная фильтрация одометрии и абсолютных позы ArUco с помощью **2D Комплементарного фильтра (Complementary Filter)**.
   - Нода локализации экстраполирует позу робота на частоте 25 Гц на основе колесной одометрии, а при проезде под метками дрейф мгновенно корректируется с весом `filter_alpha` (по умолчанию `0.20`). Это убирает jitter и дрейф.

3. **Прошивка ESP32 под шаговые двигатели NEMA**:
   - Написана прошивка в `firmware/esp32_stepper_driver/` на базе библиотеки **`AccelStepper`**.
   - Реализован последовательный протокол обмена скоростями и одометрией по USB-Serial.
   - Встроен **защитный таймер (Watchdog)** на 500 мс для экстренной остановки.

4. **ROS 2 Мост связи (`esp32_bridge`)**:
   - Нода `esp32_bridge.py` рассчитывает прямую и обратную кинематику 3-колесной Omni платформы.
   - Читает скорости из `/cmd_vel` ➔ шлет в ESP32; получает шаги колес от ESP32 ➔ публикует `/wheel_odom`.
   - Встроены калибровочные множители радиуса колес и базы для настройки на лету.

5. **Автопилот (Pure Pursuit)**:
   - Создана нода `path_follower.py`, реализующая алгоритм Pure Pursuit для всенаправленных роботов.
   - Нода ведет робота по траектории (топик `/plan`), разворачивает его по направлению движения и плавно замедляет робота перед финишной точкой до полной остановки (допуск `goal_tolerance` = 8 см).

6. **Калибровка, Ручное управление и Маршруты в Web UI**:
   - Веб-интерфейс на порту `8080` содержит:
     - Панель динамической калибровки колес и базы.
     - Виртуальный тач-джойстик (Vx, Vy) и кнопки вращения на месте для ручного пилотирования.
     - Режим рисования траекторий на Canvas кликами с кнопками запуска и очистки маршрутов.
     - Красную кнопку экстренного останова.

7. **Единые файлы запуска**:
   - `run_robot.launch.py`: запуск локализации и управления вручную.
   - `run_autonav.launch.py`: запуск локализации, моста моторов и автопилота Pure Pursuit.

2. **Интеграция датчика IMU N100 wheeltec**: Подключить IMU к RPi 5, запустить его ноду и добавить угловую скорость/ускорение с гироскопа в комплементарный фильтр слияния для повышения точности ориентации.
