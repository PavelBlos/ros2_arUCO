# Поиск Raspberry Pi в новой Wi-Fi-сети

Запустите `start_raspberry_finder.bat`. Приложение само определит активную
локальную сеть, найдёт веб-пульт TERMIT и покажет IP-адрес робота.

В окне можно:

- повторить поиск после смены Wi-Fi;
- скопировать IP-адрес;
- открыть веб-пульт двойным щелчком или отдельной кнопкой;
- вручную указать небольшую подсеть, например `172.20.10.0/28`.

Приложение использует только стандартную библиотеку Python и не требует
установки дополнительных пакетов. Для диагностики доступен консольный режим:

```powershell
python .\find_raspberry_pi.pyw --scan
```
